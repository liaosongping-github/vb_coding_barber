# 邻剪平台知识库

## 目录用途
保存跨版本持续有效的平台知识，是业务与工程事实的唯一权威入口。
## 内容索引
- `business/`：战略、用户、术语、业务规则和流程。
- `engineering/`：人工架构知识与自动代码图谱。
- `decisions/`：重要产品和技术决策。
- `releases/`：线上版本与知识版本绑定。
- `governance/`：文档、Agent 和发布治理。
## 使用入口
先阅读本文件和 `releases/v0.1.md`，再按任务进入业务或工程知识。
## 上下游关系
接收产品、研发、测试的已确认产出，并为后续工作提供稳定上下文。
## 维护规则
事实变化必须与交付物同批更新；自动生成内容禁止手改。
## 当前状态
当前线上版本为 v0.1；正式生产工程尚未启动。
