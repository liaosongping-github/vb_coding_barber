# 术语表

| 术语 | 定义 |
|---|---|
| 取号 | 顾客加入某次营业队列并获得一个或多个连续号码。 |
| 预约 | v0.1 不采用未来日期预约；文档中应统一使用“当天取号”。 |
| 有效号码 | 等待中、待核验、服务中、已过号待沟通或已顺延的号码。 |
| 待核验 | 当前服务结束后，理发师需要确认顾客是否到场的候选号码。 |
| 过号 | 顾客未到场，理发师将号码移出普通等待序列。 |
| 顺延 | 过号顾客到场沟通后，经理发师确认进入优先队列。 |
| 营业场次 | 理发师一次开店至关店的业务会话，绑定当次服务地址。 |
| 动态估时 | 前方未完成号码数乘以平均单客时长得到的参考时间。 |
| 冻结版本 | 已定稿、不可直接覆盖的产品交付基线。 |
