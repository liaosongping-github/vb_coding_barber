# 工程知识

## 目录用途
保存可跨版本复用的架构事实和与代码同步生成的知识图谱。
## 内容索引
- `architecture/`：人工维护的系统边界、领域模型与关键链路。
- `generated/`：从代码自动生成的模块、依赖、路由、类型和测试索引。
## 使用入口
先读架构，再使用 generated 中的索引定位代码。
## 上下游关系
输入来自研发交付和已接受 ADR；输出供研发、测试和发布 Agent 使用。
## 维护规则
架构变更更新人工文档；代码变化运行 `pnpm knowledge:generate`，不得手改生成文件。
## 当前状态
仅记录 v0.1 原型；生产工程尚未启动。
