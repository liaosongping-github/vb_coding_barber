# 系统上下文

v0.1 是单页 Web 高保真交互原型，通过顶部切换模拟用户端、理发师端和管理端，通过内存状态模拟取号、推进、取消、过号、顺延和营业状态变化。它没有生产数据库、真实微信身份、订阅消息或地图服务。

目标生产系统的逻辑边界包括：

- 用户微信小程序：发现理发师、取号、查看和管理号码。
- 理发师微信小程序：开关店、地址管理、队列推进和服务记录。
- 管理微信小程序：入驻、账号管理和记录查询。
- 服务端：负责身份、队列原子变更、动态估时、通知和记录持久化。

生产技术栈、仓库拆分、部署拓扑和基础设施尚未决策，不能从原型结构直接推导。
