# Agent 接手与交接

## 接手

1. 按根 `AGENTS.md` 的顺序建立上下文。
2. 确认最新发布记录、当前任务版本和冻结边界。
3. 阅读目标目录的 README 与局部 AGENTS。
4. 运行只读状态检查，确认工作树和当前基线。

## 工作中

- 不把关键决策只留在对话中。
- 发现知识与代码冲突时记录并优先修复权威来源。
- 修改业务、架构或测试时同步相邻交付物。

## 交接

交接必须说明完成内容、未完成内容、验证结果、变更文档、风险和下一步；若已发布，还需更新发布绑定。
