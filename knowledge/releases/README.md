# 发布记录

## 目录用途
绑定产品版本、Git 提交、知识图谱、部署地址和验收结果。
## 内容索引
每个正式版本使用同名 Markdown 记录；当前包含 `v0.1.md` 与 `v0.2.md`，部署后的机器字段由发布绑定工具更新。
## 使用入口
先阅读最新版本记录，确认线上事实后再开展工作。
## 上下游关系
输入来自产品、研发、测试和部署结果；输出是线上版本的权威指针。
## 维护规则
只有发布流程可将状态改为 deployed；不得删除历史记录。
## 当前状态
v0.1 已部署；v0.2 原型已定稿、尚未部署。
