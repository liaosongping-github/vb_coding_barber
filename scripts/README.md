# 工作空间工具

## 目录用途
保存可重复运行的知识、治理和发布辅助脚本。
## 内容索引
`knowledge/` 负责图谱生成、工作空间检查、版本冻结和发布绑定。
## 使用入口
通常通过根 `package.json` 中的 `knowledge:*` 与 `release:*` 命令调用。
## 上下游关系
输入为受管文档和源码，输出为自动图谱、冻结清单和发布记录。
## 维护规则
脚本必须跨平台、无交互、结果确定且不得写入冻结版本，冻结工具除外。
## 当前状态
工作空间 v0.1 工具已建立。
