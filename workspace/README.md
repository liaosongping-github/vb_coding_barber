# 角色交付工作区

## 目录用途
按产品、研发和测试角色保存可交接、可验收、可版本化的工作产出。
## 内容索引
`product/` 保存需求与原型；`engineering/` 保存生产工程；`testing/` 保存测试资产。
## 使用入口
根据当前角色进入对应目录，先读 README 和局部 AGENTS。
## 上下游关系
产品交付给研发，研发交付给测试，三方共同完成验收发布。
## 维护规则
交付物必须标注状态和适用版本；定稿版本禁止覆盖。
## 当前状态
产品 v0.1 已定稿；研发和测试工作区完成初始化。
