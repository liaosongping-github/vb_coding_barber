# 产品交付区

## 目录用途
保存产品角色完成的需求、PRD、验收标准和可运行定稿原型。
## 内容索引
每个产品版本独立建目录；当前研发版本为 `v0.2/`，`v0.1/` 保持冻结。
## 使用入口
先读对应版本 README，再读 PRD、验收标准并运行原型。
## 上下游关系
输入来自业务知识和产品决策；定稿后交给研发和测试。
## 维护规则
定稿版本禁止覆盖；任何交互或规则变化必须创建新版本。
## 当前状态
v0.1 与 v0.2 均已定稿，v0.2 正在执行冻结发布门禁。
