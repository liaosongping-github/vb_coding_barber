# 产品交付 v0.1

## 目录用途
保存邻剪首个高保真原型版本的完整产品交付基线。
## 内容索引
`PRD.md` 描述需求；`acceptance-criteria.md` 描述验收；`prototype/` 是可运行原型；`FROZEN.json` 是冻结清单。
## 使用入口
先读 PRD 和验收标准，再在仓库根目录运行 `pnpm prototype:dev`。
## 上下游关系
输入来自 v0.1 业务规则；输出作为后续研发和测试基线。
## 维护规则
本目录冻结后不可直接修改；新需求建立新版本目录。
## 当前状态
