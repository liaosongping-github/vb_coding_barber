# 邻剪 v0.1 可运行原型

## 目录用途
保存已经定稿的三端 Web 高保真交互原型源码。
## 内容索引
`app/` 是界面与交互；`public/` 是静态资源；`tests/` 是冒烟测试；其余目录为构建和托管基础设施。
## 使用入口
在仓库根目录运行 `pnpm prototype:dev`、`pnpm prototype:build` 或 `pnpm prototype:test`。
## 上下游关系
输入为 v0.1 PRD；该原型是研发与测试理解产品交互的参考，不是生产代码。
## 维护规则
本目录受冻结清单保护，不得直接修改；后续原型新建版本。
## 当前状态
v0.1 已定稿并在线运行。
