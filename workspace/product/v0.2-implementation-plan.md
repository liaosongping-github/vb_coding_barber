# v0.2 试运行 MVP 原型实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在不修改冻结 v0.1 的前提下，交付只保留首页和我的排队、完全移除地图与收藏及用户个人页的 v0.2 可运行原型。

**Architecture:** 从 v0.1 冻结交付复制出独立 v0.2 产品版本，保持单页内存状态原型和理发师端、管理端行为不变，只收缩用户端组件与地址交互。根脚本和自动代码图谱切换到 v0.2，v0.1 与 v0.2 各自使用冻结清单保护。

**Tech Stack:** React 19、TypeScript、Vinext/Vite、Node.js 内置测试、pnpm、Markdown 知识库治理脚本。

**Spec:** `knowledge/decisions/ADR-0004-v0.2试运行MVP范围.md`

## Global Constraints

- `workspace/product/v0.1/` 不得修改。
- 用户端底部导航只保留“首页”和“我的排队”。
- 用户端不得出现地图、定位、导航、距离、收藏和用户个人页入口。
- 理发师服务地址以文字保留；开店不依赖地图定位。
- 理发师端、管理端和 v0.1 队列闭环不得回归。
- 每个独立交付单元使用中文提交说明。
- 所有人工维护目录必须包含符合治理模板的 `README.md`。
- 不手工修改 `knowledge/engineering/generated/`；只能运行生成器更新。
