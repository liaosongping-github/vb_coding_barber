# 邻剪 v0.2 可运行原型

## 目录用途
保存试运行 MVP 研发中的三端 Web 高保真交互原型源码。
## 内容索引
`app/` 是界面与交互；`public/` 是静态资源；`tests/` 是冒烟测试；其余目录为构建和托管基础设施。
## 使用入口
在仓库根目录运行 `pnpm prototype:dev`、`pnpm prototype:build` 或 `pnpm prototype:test`。
## 上下游关系
输入为 v0.2 PRD 与 ADR-0004；该原型是研发与测试理解产品交互的参考，不是生产代码。
## 维护规则
本目录为可修改的 v0.2 产品基线；v0.1 冻结原型不得直接修改。
## 当前状态
v0.2 试运行 MVP 研发中。
