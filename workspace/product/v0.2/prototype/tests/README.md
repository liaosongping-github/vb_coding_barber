# 原型自动化测试

## 目录用途
验证 v0.2 原型能够构建，并持续覆盖试运行 MVP 的关键页面、交互入口和精简后的用户端范围。
## 内容索引
`prototype.test.mjs` 包含源代码范围断言和构建冒烟测试：用户端只保留首页和我的排队，不包含地图、定位、导航、距离、收藏或个人页能力。
## 使用入口
从根目录运行 `pnpm prototype:test`。依赖不完整时，可使用 Node 直接运行源文本测试，并通过 `--test-name-pattern` 跳过构建与 Worker 测试。
## 上下游关系
输入来自 v0.2 验收标准，结果交给发布门禁。
## 维护规则
测试随 v0.2 原型需求更新，并保持测试过程不改写被测源码。
## 当前状态
随 v0.2 试运行 MVP 研发持续更新。
