# 测试交付区

## 目录用途
保存测试角色产出的测试策略、用例、自动化脚本和验收结果。
## 内容索引
`test-cases/` 保存业务用例；`automation/` 保存自动检查说明和后续脚本。
## 使用入口
先确定被测产品版本，再读取对应 PRD、验收标准和测试用例。
## 上下游关系
输入来自产品验收标准和研发实现；结果用于验收发布。
## 维护规则
每条定稿业务规则至少对应一个测试场景；缺陷修复必须增加回归覆盖。
## 当前状态
v0.1 与 v0.2 用例已建立，v0.2 自动化覆盖构建、范围和关键交互回归。
