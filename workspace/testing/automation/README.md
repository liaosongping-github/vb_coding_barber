# 自动化测试

## 目录用途
说明和承载跨产品版本的自动化测试脚本。
## 内容索引
当前自动化脚本位于 v0.1 原型的 `tests/`；生产工程启动后在此建立共享测试套件。
## 使用入口
从仓库根目录运行 `pnpm test` 或 `pnpm release:check`。
## 上下游关系
输入来自测试用例和研发实现；输出供发布门禁使用。
## 维护规则
脚本必须无交互、可重复、失败信息可定位，不修改冻结交付物。
## 当前状态
已覆盖工作空间治理、原型构建和源代码冒烟检查。
