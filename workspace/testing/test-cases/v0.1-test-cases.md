# v0.1 测试用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| U-01 | 同一理发师多人取号 | 选择 3 人并确认 | 生成 3 个连续号码并分别展示状态。 |
| U-02 | 多理发师取号上限 | 已持有 2 个号码后在另一理发师取 2 人 | 系统阻止超过 3 个有效号码。 |
| U-03 | 取消单号 | 取消多人取号中的一个号码 | 仅目标号码取消，后方位置和估时更新。 |
| U-04 | 营业卡片 | 查看首页和收藏页 | 所有营业中卡片有立即取号，歇业卡片没有。 |
| U-05 | 地图过滤 | 切换地图 | 只展示营业中理发师，气泡含头像和名称。 |
| U-06 | 排队分类 | 切换三个排队标签 | 分别展示进行中、已过号、已完成数据。 |
| B-01 | 正常推进 | 完成当前服务并开始下一号 | 当前号完成，下一候选正确展示并进入服务。 |
| B-02 | 过号顺延 | 对候选过号后确认顺延 | 号码进入顺延队列并优先于普通等待。 |
| B-03 | 强制关店 | 队列非空时关店 | 二次确认，非服务中号码批量过号。 |
| B-04 | 地址开店 | 选择历史地址或新增地址 | 当次营业地址同步到用户端展示。 |
| B-05 | 数据看板 | 进入数据页 | 展示营业额估算、完成、过号和取消数量。 |
| A-01 | 管理权限 | 查看理发师、用户和记录 | 可查看和启停账号，不出现实时队列编辑入口。 |
| N-01 | 拒绝通知 | 拒绝订阅后取号 | 允许取号并明确显示无法收到提醒的风险。 |
| N-02 | 临近提醒 | 号码前方从 4 人变为 3 人 | 只触发一次临近提醒。 |
