# v0.2 验收用例

| 编号 | 场景 | 操作 | 预期结果 |
|---|---|---|---|
| U2-01 | 两项导航 | 打开用户端 | 仅显示首页和我的排队。 |
| U2-02 | 首页取号 | 在营业理发师详情确认取号 | 生成号码并进入我的排队的进行中。 |

| U2-04 | 排队空态 | 清空进行中号码 | 仅显示“无排队”。 |
| B2-01 | 文字地址开店 | 选择历史地址或输入新地址 | 成功开店，不依赖地图。 |
| B2-02 | 队列顺延 | 对过号号码确认顺延 | 号码排在“下一位”之后、普通等待之前。 |
| B2-03 | 资料编辑 | 修改姓名、营业时间和平均时长 | 保存后立即回显。 |
| R2-01 | 三端回归 | 推进队列并查看管理端 | 理发师和管理端核心流程正常。 |
